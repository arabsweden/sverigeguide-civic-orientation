# SverigeGuide · Civic Orientation 🇸🇪

**Trilingual civic orientation platform for newcomers to Sweden**

Arabic · Svenska · English

---

## ✨ Features

- 📚 Learning modules on Swedish society, rights and obligations
- ❓ Interactive question bank
- 🤖 AI civics advisor powered by Google Gemini (server-side)
- 🏛️ Directory of Swedish authorities
- ⚖️ Law tracker
- 🏙️ Municipal hub

## 🛠️ Tech stack

TypeScript · React · Vite · Tailwind CSS · Express · Google Gemini API

## 🚀 Run locally

```bash
npm install
cp .env.example .env.local   # add your own GEMINI_API_KEY
npm run dev
```

> 🔐 Never commit real API keys. `.env` files are ignored by git.
